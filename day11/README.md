# Day 11｜三個 IP 分別落在哪個範圍？

## 題目情境

在 AWS 中，我們使用 VPC 定義網路範圍，再從中劃分出 Subnet。判斷一個 IP 位址落在哪段範圍時，需同時看 CIDR 的起始位址和斜線後的數字：斜線後的數字代表範圍大小，起始位址則決定範圍從哪裡開始。

本題的範圍如下：

- VPC `10.0.0.0/16`：`10.0.0.0～10.0.255.255`
- Front `10.0.1.0/24`：`10.0.1.0～10.0.1.255`
- Data `10.0.2.0/24`：`10.0.2.0～10.0.2.255`
- 待判斷的 IP：`10.0.1.24`、`10.0.3.24`、`10.1.1.24`

只根據題目列出的位址範圍判斷，不推測主機是否存在、IP 是否已配置或網路是否能連線。

## 第 1 題－從 IP 範圍能確定什麼（單選）

`10.0.1.24` 落在 Front 的範圍（`10.0.1.0～10.0.1.255`）內。根據這項資訊，可以確定什麼？

A. 這個地址已由 AWS 配置給某台主機，只是圖上沒有畫出來。  
B. 這個地址通常可以從 Internet 連入，因為它落在 VPC 的範圍內。  
C. 這個地址在 Front 內，但也可能同時落在 Data 內，要再比對一次。  
D. 這個地址屬於 Front 的範圍；主機是否存在，題目沒有提供。

### 答案

D

### 理由

`10.0.1.24` 在 Front 的位址範圍內，因此可以確定它屬於這段範圍。題目沒有提供主機或 IP 配置資訊，不能進一步判斷主機是否存在或已取得這個 IP。

### 這題要記住

落在 Subnet 的 CIDR 範圍內，只能說明位址屬於該範圍，不能據此推論 IP 已配置給主機或能從 Internet 連入。

## 第 2 題－比較三個 IP 的範圍（複選，請選 2 項）

根據上圖的範圍，以下哪些敘述正確？

A. `10.0.3.24` 不在 Front 或 Data，所以應該也落在 VPC 之外。  
B. `10.0.1.24` 在 Front 內，也同時在 VPC 的範圍內。  
C. `10.1.1.24` 的最後兩段與 `10.0.1.24` 相同，因此也在 Front。  
D. `10.0.3.24` 在 VPC 範圍內，但不屬於圖中的 Front 或 Data。  
E. Front 與 Data 都是 `/24`，所以兩者包含的是同一批 IP。

### 答案

B、D

### 理由

Front 的範圍在 VPC 範圍內，所以 `10.0.1.24` 同時屬於 Front 和 VPC。`10.0.3.24` 符合 VPC 的 `10.0.0.0/16`，但不在圖中列出的 Front 或 Data Subnet 範圍內。

## 第 3 題－改變 IP 的第三段（單選）

如果把 `10.0.1.24` 的第三段從 1 改成 2，得到 `10.0.2.24`，圖中的 VPC、Front 和 Data 範圍都不變。新位址落在哪裡？

A. Data Subnet，且仍在同一個 VPC 範圍內。  
B. Front Subnet，因為最後一段仍是 24。  
C. VPC 外，因為第三段一改，多半就離開原本的 `/16` 範圍了。  
D. 同時屬於 Front 與 Data，因為兩者都是 `/24`。

### 答案

A

### 理由

`10.0.2.24` 位於 Data 的 `10.0.2.0～10.0.2.255` 範圍內，也符合 VPC `10.0.0.0/16` 的位址範圍。

### 這題要記住

相同的 `/24` 代表範圍大小相同，不代表兩段包含同一批 IP。`10.0.1.0/24` 和 `10.0.2.0/24` 起始位址不同，範圍也不同；而 `/16` 的 VPC 可以涵蓋多個 `/24` Subnet 或其他位址範圍。
