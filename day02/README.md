# Day 02｜同樣有兩台主機，放在不同 AZ 會有什麼差別？

## 題目情境

同一個 Region 包含多個彼此隔離的可用區（Availability Zone，簡稱 AZ）。因此，建立第二台主機時，除了確認主機數量，也需要留意它實際放在哪個 AZ。

### 比較兩份部署草圖

現在有方案甲與方案乙兩種部署方式，兩個方案中的 Web 1 與 Web 2 都部署在同一個 Region。

* 方案甲：Web 1、Web 2 都在 AZ 1
* 方案乙：Web 1 在 AZ 1、Web 2 在 AZ 2

目前發生一個突發狀況：**AZ 1 發生故障而無法使用，但 AZ 2 仍正常。**

面對這次的故障，同樣都有兩台主機的方案甲與方案乙，各自是否還有主機能正常運作？

> 即使還有主機能正常運作，也不代表它已經自動接手故障主機原本的服務。

---

## 第 1 題－從部署圖能確認哪些資訊（複選）

先不考慮前述的故障情況，只看兩個方案的部署圖，以下哪兩項資訊可以直接從圖中確認？

A. 方案甲有兩台 Web 主機。
B. 方案乙的兩台主機位於不同 Region。
C. 方案甲與方案乙都已設定好流量切換，當一台主機故障時，會將流量轉到另一台主機。
D. 方案乙的兩台主機位於不同 AZ。
E. 方案甲的兩台主機保存的是同一份資料。

### 答案

**A、D**

### 理由

從部署圖可以直接看到主機的數量，以及主機分別位於哪個 AZ。

方案甲有 Web 1、Web 2 兩台主機；方案乙的兩台主機分別位於 AZ 1 和 AZ 2。

至於流量切換、資料同步等設定，圖中沒有提供足夠資訊，因此不能直接判斷。

---

## 第 2 題－當整個 AZ 無法使用時（單選）

在前述 AZ 1 無法使用、AZ 2 仍正常的情況下，兩個方案各自是否還有主機能正常運作？請選出正確的比較結果。

A. 兩個方案都還有一台正常主機，因為方案甲的 Web 2 是另外建立的備援主機。
B. 只有方案甲還有正常主機，因為方案甲的兩台主機在同一個 AZ，可以直接互相接手服務。
C. 兩個方案都沒有正常主機，因為 AZ 1 與 AZ 2 同屬一個 Region，會一起受到故障影響。
D. 只有方案乙還有一台正常主機，因為它的 Web 2 位於仍正常的 AZ 2。

### 答案

**D**

### 理由

AZ 1 發生故障時，位於 AZ 1 的主機都會受到影響。

方案甲的 Web 1、Web 2 都在 AZ 1，因此兩台都無法正常運作。

方案乙的 Web 1 在 AZ 1，但 Web 2 在仍正常的 AZ 2，因此 Web 2 還能正常運作。

### 這題要記住

**同一個 Region 裡的不同 AZ 是彼此隔離的。**

因此，將主機分散到不同 AZ，可以降低單一 AZ 故障時整體都無法運作的風險。

---

## 第 3 題－當 Web 1 的應用程式故障時（單選）

這一題假設另一種故障情況發生：

**AZ 1 與 AZ 2 都正常，兩個方案都只有 Web 1 的應用程式崩潰，Web 2 則仍能正常運作。**

若只比較兩個方案是否還有主機能正常運作，以下哪一項說明正確？

A. 兩個方案的 Web 2 都能正常運作，沒有受到這次故障影響。
B. 只有方案乙還有正常主機，因為方案甲的 Web 2 與 Web 1 在同一個 AZ，不能將 Web 2 視為未受影響的主機。
C. 兩個方案的 Web 2 都不能算是正常主機，因為流量還沒有切換到 Web 2。
D. 兩個方案的服務都可視為沒有中斷，因為 Web 2 仍正常。

### 答案

**A**

### 理由

這次故障是 **Web 1 的應用程式故障**，而不是 AZ 故障。

題目已經明確說明 Web 2 仍能正常運作，因此不論方案甲或方案乙，Web 2 都還是一台正常運作的主機。

但「Web 2 還能正常運作」不代表使用者的流量已經自動切換過去，因此不能直接推論整個服務沒有中斷。

### 這題要記住

要分清楚不同層級的故障：

* **AZ 故障**：該 AZ 裡的主機都可能受到影響。
* **單一主機／應用程式故障**：不代表同 AZ 的其他主機也一定故障。
* **主機正常運作**：也不等於流量已經自動切換，或整個服務對使用者仍然正常。
