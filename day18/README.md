# Day 18｜SSH 能連上，來源範圍該怎麼限縮？

## 題目情境

Security Group（SG）的 Inbound 規則會檢查哪些連線可以進入主機。每條規則會同時比對 Port 和 Source：Port 指定服務入口，Source 指定允許的來源範圍；連線必須同時符合兩者，才符合該規則。

Source 可以用「IPv4 位址/前綴長度」表示範圍。例如，`203.0.113.10/32` 只包含一個 IPv4 地址，`0.0.0.0/0` 則涵蓋所有 IPv4 來源。

一台提供會員網站的主機只掛載 `web-sg`，目前 Inbound 規則如下：

| 用途 | Protocol | Port | Source |
| --- | --- | --- | --- |
| 網站 HTTPS | TCP | 443 | `0.0.0.0/0` |
| SSH | TCP | 22 | `0.0.0.0/0` |

SSH 規則是同事剛新增的。他表示 SSH 已可連線，但主管要求只允許目前辦公室的公有出口 IP。依照主管要求與網站用途，來源應設定為：

- **SSH（TCP 22）：** 只允許辦公室目前的出口 IP `203.0.113.10`
- **網站 HTTPS（TCP 443）：** 所有會員都要能連入，不限連線地點

本題只判斷 SG；路由與服務皆已確認正常。

## 第 1 題－比較 SSH 規則的來源範圍（單選）

若 SSH 規則的 Source 分別設為 `203.0.113.10/32` 與 `0.0.0.0/0`，兩者允許的來源有什麼差別？

A. `/32` 表示最多 32 台來源主機；`/0` 表示沒填來源，不放行。  
B. `/32` 只允許辦公室裡填寫規則的那一台電腦；`/0` 才允許辦公室的其他電腦。  
C. `/32` 涵蓋的來源比 `/0` 多，因為斜線後的數字較大；`/0` 只有 `0.0.0.0` 一個地址。  
D. `/32` 指定一個 IPv4 地址；`/0` 涵蓋所有 IPv4 來源。

### 答案

D

### 理由

`/32` 表示來源範圍只有指定的單一 IPv4 地址；`/0` 則涵蓋所有 IPv4 來源。因此 SSH 使用 `/32` 可以把來源限縮到辦公室目前的出口 IP。

## 第 2 題－修正辦公室 SSH 的來源（單選）

根據情境需求，以下哪個修正，能讓 SSH 只允許目前辦公室出口，同時讓所有會員繼續使用 HTTPS？

A. 網站那列的 Source 改成 `203.0.113.10/32`。  
B. SSH 那列的 Port 改成 443。  
C. SSH 那列的 Source 改成 `203.0.113.0/24`，保留同段其他出口。  
D. SSH 那列的 Source 改成 `203.0.113.10/32`。

### 答案

D

### 理由

只要把 SSH TCP 22 規則的 Source 改成辦公室出口 IP 的 `/32`，就能限制 SSH 的來源。HTTPS 規則保持 `0.0.0.0/0`，所有會員仍能連入。

## 第 3 題－新增家中 SSH 來源（複選，請選 2 項）

第 2 題的修正已完成：辦公室 SSH 規則的 Source 已改為 `203.0.113.10/32`，網站 HTTPS 仍供所有會員使用。

同事現在也需要從家中使用 SSH。家中目前的出口 IP 是 `198.51.100.20`，但網路重新連線後可能改變。為了知道維運時家中使用的是哪個 IP，他每次維運前都可以先確認當時的出口 IP。

在設定家中 SSH 時，還要符合以下要求：

- 保留辦公室的 SSH 權限，以及所有會員的 HTTPS 連線。
- 家中 SSH 只允許當時確認的單一出口 IP；IP 變更後，不保留失效的舊地址。

以下哪兩項 SG 設定或更新方式符合要求？

A. 新增 SSH TCP 22、Source=`198.51.100.20/32`，保留辦公室 SSH 與原 HTTPS 規則。  
B. 將原辦公室 SSH 的 Source 換成家中 `/32`，讓 SSH 規則維持一條以減少開放。  
C. 家中出口變更時，確認新 IP，再將家用 SSH 規則的舊 `/32` 更新為新 `/32`。  
D. 用 `198.51.100.0/24` 作家用 SSH Source，預留同網段地址，減少重連後的更新。  
E. 維運期間把 SSH Source 設為 `0.0.0.0/0`，結束後再收回，以時間限制取代地址更新。

### 答案

A、C

### 理由

新增一條只允許家中當前出口 IP 的 SSH `/32` 規則，可以保留辦公室 SSH 和所有會員的 HTTPS。家中出口 IP 變更後，先確認新 IP，再把家用規則中的舊地址更新成新地址，避免繼續保留已失效的來源。

### 這題要記住

CIDR 前綴數字越大，涵蓋的地址範圍越小。用 `/32` 可把規則限縮到單一 IPv4 地址；若來源 IP 會變動，應依新的出口 IP 更新規則，而不是長期使用較大的範圍。
