# Day 12｜改了 Subnet 名稱，也改了路由：哪個會影響對外路由？

## 題目情境

判斷一個 Subnet 是否具有 Public Subnet 的路由特徵，要查看它關聯的路由表，確認是否有直接通往 Internet Gateway（IGW）的路由。

Subnet 的「自動指派公有 IPv4」設定，影響主機的地址配置，和路由表是不同設定。

今天的圖比較的是同一個 Subnet 在設定變更前後的狀態。變更前後都關聯名為 `rt-app` 的路由表，IGW 也一直連接在這個 Subnet 所屬的 VPC 上。

| 查看的設定 | 變更前 | 變更後 | 是否改變 |
| --- | --- | --- | --- |
| Subnet 名稱 | `public-app` | `private-app` | 有 |
| 自動指派公有 IPv4 | 關閉 | 關閉 | 沒有 |
| `rt-app` 的 local 路由 | `10.0.0.0/16 → local` | `10.0.0.0/16 → local` | 沒有 |
| `rt-app` 的 IGW 預設路由 | 沒有 | `0.0.0.0/0 → IGW` | 有 |

本題只討論 Subnet 設定與對外路由，不判斷特定主機是否已能連上網站。

## 第 1 題－分辨名稱、地址與路由（複選，請選 2 項）

這題改用另一個假設情境，不沿用上圖的變更前後狀態：

- 某個 Subnet 的名稱改為 `public`
- 自動指派公有 IPv4 改為開啟
- 關聯的路由表沒有改變，完整路由仍只有 `10.0.0.0/16 → local`

根據以上設定，哪兩項判斷成立？

A. 路由表只有 local，表示它目前連 VPC 內的其他 Subnet 也到不了。  
B. 就對外路由而言，這個 Subnet 目前仍缺少直接通往 IGW 的路由。  
C. 開啟自動指派只改變地址配置，不會替路由表補上 IGW 項目。  
D. 公有 IPv4 指派開著，代表這個 Subnet 裡目前至少有一台主機拿到公有 IP。  
E. Public 或 Private 是建立 Subnet 時就選定的屬性，改路由也不會改變。

### 答案

B、C

### 理由

路由表只有 local，表示沒有直接通往 IGW 的對外路由。自動指派公有 IPv4 是地址配置設定，不會替路由表新增路由；它也不能證明目前已有主機取得公有 IP。

## 第 2 題－比較同一個 Subnet 的變更前後（單選）

回到今天的情境，在上圖的設定變更對照，以下哪一項結論正確？

A. 名稱從 public 改成 private，因此它從 Public 變成 Private Subnet。  
B. 前後應該都不算 Public Subnet，因為自動指派公有 IPv4 兩次都是關閉。  
C. 新增 IGW 路由使變更後具有 Public Subnet 的路由特徵，名稱不決定分類。  
D. 前後都是 Public Subnet，因為 VPC 已連接 IGW，不必再看關聯路由表。

### 答案

C

### 理由

變更前後的名稱不同，但名稱只是標籤。真正改變路由特徵的是 `rt-app` 新增了 `0.0.0.0/0 → IGW`；只連接 IGW 的 VPC，不代表每個 Subnet 都有通往 IGW 的路由。

## 第 3 題－路由不變，另外調整兩項設定（單選）

這題延續上圖的變更後狀態，並再進行一次調整：

| 查看的設定 | 這一題的狀態 |
| --- | --- |
| Subnet 名稱 | 由 `private-app` 改回 `public-app` |
| 自動指派公有 IPv4 | 由關閉改為開啟 |
| `rt-app` 的路由 | 沒有改變，仍有 `10.0.0.0/16 → local` 與 `0.0.0.0/0 → IGW` |
| IGW | 仍連接在同一個 VPC 上 |

根據以上條件，哪一項說明正確？

A. 路由特徵維持不變；公有 IPv4 指派打開後，既有主機也會自動補上公有 IPv4。  
B. 之後啟動的新主機預設會拿到公有 IPv4，等於已能對外，因此可以移除 `0.0.0.0/0 → IGW`。  
C. Public Subnet 路由特徵不變；自動指派影響之後啟動主機時的預設公有 IPv4 配置。  
D. 名稱與公有 IPv4 指派一起調整後，已足以確認既有主機有公有 IPv4，而且能從 Internet 連入。

### 答案

C

### 理由

路由表沒有改變，仍有通往 IGW 的路由，因此 Subnet 的路由特徵不變。開啟自動指派會影響之後啟動主機時的預設公有 IPv4 配置，但不會回頭替既有主機補上地址，也不能單獨證明主機能從 Internet 連入。

### 這題要記住

Subnet 名稱、自動指派公有 IPv4 和路由表是不同設定。判斷 Public Subnet 的路由特徵要看關聯路由表；要判斷特定主機能否連線，還需要更多主機與網路設定資訊。
