# Day 15｜從目的 IP 判斷封包會使用哪條路由

## 題目情境

路由表會依封包的目的 IP，決定要使用哪一條路由。如果目的 IP 同時符合多條路由，會選擇範圍較具體的路由。例如，`10.0.0.0/16` 的範圍比涵蓋所有 IPv4 地址的 `0.0.0.0/0` 更小，因此更具體。

Web 主機送出兩個封包：

- 封包 ① 的目的 IP：`10.0.2.50`，是同一個 VPC 內另一台主機的 IP。
- 封包 ② 的目的 IP：`198.51.100.20`，本題把它當作範例目的地址，並非真實測試服務。

Web 所在 Subnet 的完整 IPv4 路由如下：

| Destination | Target |
| --- | --- |
| `10.0.0.0/16` | `local`（VPC 內部路徑） |
| `0.0.0.0/0` | `IGW` |

本題只比對目的 IP 與路由範圍，不判斷封包最後能否連上目的主機或服務。

## 第 1 題－兩條路由都符合時（單選）

封包 ① 的目的 IP `10.0.2.50` 同時符合 `10.0.0.0/16` 與 `0.0.0.0/0`。應選哪條路由？

A. 兩條都符合時，通常依表中排列順序，後列出的那條會覆蓋前面的。  
B. 將封包各複製一份到 local 與 IGW。  
C. 選 `/16` 的 local，因為它的匹配範圍更具體。  
D. 選 `/0` 的 IGW，因為它能匹配更多地址，比較不會漏掉。

### 答案

C

### 理由

`10.0.2.50` 同時符合 `/16` 和 `/0`，但 `/16` 涵蓋的地址範圍較小、更具體，因此使用 `10.0.0.0/16 → local`。

## 第 2 題－兩個封包分別會使用哪條路由（單選）

根據前面的兩個目的 IP 與路由表，以下哪一條追蹤紀錄正確？

A. ① 走 IGW、② 走 local；因為 ① 是主機地址，② 是外部服務地址。  
B. ①、② 都走 IGW；因為 `0.0.0.0/0` 也涵蓋 `10.0.2.50`，兩條都符合時通常用預設路由。  
C. ①、② 都走 local；因為兩個封包都是從這個 VPC 裡的 Web 發出。  
D. ① 走 local、② 走 IGW；① 優先匹配較具體的 `10.0.0.0/16`。

### 答案

D

### 理由

封包 ① 的目的 IP `10.0.2.50` 落在 `10.0.0.0/16` 範圍內，使用 local 路由。封包 ② 的目的 IP `198.51.100.20` 不在 `/16` 範圍內，因此使用符合它的預設路由 `0.0.0.0/0 → IGW`。

## 第 3 題－移除預設路由（複選，請選 2 項）

現在從表中刪除 `0.0.0.0/0 → IGW`，只留下 `10.0.0.0/16 → local`，沒有其他路由。如果 Web 再送出目的 IP 相同的兩個封包，以下哪兩項成立？

A. 目的 `10.0.2.50` 仍能匹配 `10.0.0.0/16`，選到 local。  
B. 目的 `198.51.100.20` 會改由 local 那條路由接手送出。  
C. 刪掉預設路由後，兩個目的地應該都找不到匹配的路由。  
D. 目的 `198.51.100.20` 在剩下的路由中找不到匹配項目。  
E. 既然仍匹配 local，目的主機上的應用程式大致就能正常回應。

### 答案

A、D

### 理由

刪除預設路由後，`10.0.2.50` 仍符合保留的 `10.0.0.0/16 → local`。`198.51.100.20` 不在 `/16` 範圍內，且 `/0` 已移除，因此沒有符合它的路由。

### 這題要記住

路由表依目的 IP 選擇下一站。當多條路由都符合時，選擇範圍較具體的路由；找到路由只代表有對應的下一站，不保證目的服務一定能回應。
